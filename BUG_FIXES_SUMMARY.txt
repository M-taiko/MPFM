BUG #4: Pagination Method Error - Collection::total()
=============================================================================
Error Message:
  Method Illuminate\Database\Eloquent\Collection::total does not exist

Root Cause:
  Paginator constructor requires total parameter but was not provided
  Collection doesn't have total() method (only Paginator has it)

Solution:
  - Calculate total count before creating Paginator
  - Pass total parameter in options array
  - Use values() to reset collection keys after forPage()
  
Files Changed:
  - app/Http/Controllers/DepartmentController.php (operators method)
  
Code Fix:
  $total = $operators->count();
  $operators = new \Illuminate\Pagination\Paginator(
      $operators->forPage($page, $perPage)->values(),
      $perPage,
      $page,
      [
          'path' => request()->url(),
          'query' => request()->query(),
          'total' => $total,
      ]
  );
